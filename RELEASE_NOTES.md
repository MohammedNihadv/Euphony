## Euphony v1.0.1 — F-Droid Compliance & Desktop Polish 🎵✨

### ✨ What's New & Improvements
- **F-Droid Ready & Reproducible** — SQLite amalgamation (v3.50.2) vendored in `third_party/sqlite` and built entirely from source via Android NDK for all architectures (`arm64-v8a`, `armeabi-v7a`, `x86_64`).
- **Privacy & Battery First** — Removed background on-launch network checks; added build-time `ENABLE_UPDATES` flag.
- **Permission Cleanup** — Completely removed `REQUEST_INSTALL_PACKAGES` and broad external storage permissions. Updates now open release notes directly in the system browser.
- **Desktop Keyboard Fix** — Global shortcuts now strictly respond to dedicated media keys (Bluetooth headphones, headsets, and keyboard media buttons), preventing any interference with searching or text inputs.
- **Accurate Metadata** — Added explicit disclosures for YouTube Music streaming via InnerTube and LRCLIB lyrics.
