## Euphony v0.2.4 — Playback fix 🔧

YouTube recently changed how it serves audio, which stopped songs from playing in the previous version. This release fixes that — music loads and plays again.

### 🔧 Fixed
- **Songs now play again.** Updated the audio engine to match YouTube's latest changes, so tracks load and stream reliably.

If a song ever fails to load, try again in a moment — and please [report it](https://github.com/MohammedNihadv/Euphony/issues) if it keeps happening.
