## Euphony v0.2.1 — Premium UI Showcase & CI Polish 🚀

Euphony continues to evolve with a stunning executive product landing page, zero-warning CI/CD pipelines, and upgraded GitHub Actions workflows.

### ✨ What's New & Polished

- **Executive Product Showcase**: Re-engineered the README and hero banner (`banner.png`) with left-side glowing branding, pill badges, and cascaded dual-theme phone mockups featuring realistic glass-floor bottom reflections.
- **Zero-Warning CI & Analyzer**: Refactored `PlayerController` provider injections to avoid protected member warnings and applied `const` constructor optimizations across all UI screens (`library_screen`, `player_screen`, `lyrics_sheet`).
- **Upgraded CI Workflows**: Merged official Dependabot updates across GitHub Actions (`checkout@v7`, `upload-artifact@v7`, `download-artifact@v8`, `codeql-action@v4`, `action-gh-release@v3`) for faster and more reliable automated builds.
- **Cross-Platform Compatibility**: Fixed ASCII output in banner generation scripts and URL-encoded shield badges for pixel-perfect rendering across all GitHub clients.
